# centuryny.com

A clean, static Astro website for <https://centuryny.com>.

## Local development

Install a current Node.js LTS release, then run:

```sh
npm install
npm run dev
```

Create the production site with:

```sh
npm run build
```

Astro writes the deployable static files to `dist/`. No server runtime or WordPress/PHP environment is required.

## Content provenance

This project was initialized from an empty workspace. It intentionally contains no files copied from the previous WordPress installation, including PHP, plugins, theme JavaScript, uploads, or other unverified assets. Review and sanitize any future content before adding it to `src/` or `public/`.
